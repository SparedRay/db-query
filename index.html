Settings

Appearance

Applies to the editor and the results grid.

Syntax colours for the SQL editor. Each one is written for both the light and the dark theme, so this and the theme above are separate choices.

Defaults for new sessions

Applied at startup; the controls above the editor still win for this session.

Export

How many rows each INSERT statement carries in an exported SQL script. It barely changes how fast the export runs — but it decides how long the script takes to load, which is what you wait for when restoring one.

Measured on 100,000 rows: one row per statement loads in 274s, a hundred in 4.7s, a thousand in 1.3s. Past a thousand it buys about 1% more and makes each statement ten times longer, which is how a script runs into the server's max_allowed_packet.

Command-line agents

An agent you are already signed into can answer instead of an API key. Nothing is run, probed or offered until you turn one on.

Keys are stored in your system keychain, one per provider, never in a config file. The assistant writes SQL for you to review and run — it cannot execute anything itself. Your schema's table and column names are sent with each question; row data never is.

MCP server

Lets another tool — Claude Code, Claude Desktop, any MCP client — read the schema of the connection you have open, put a query in your editor, and write notes into its AI dictionary. It cannot run one: there is no execute tool and no way to read rows. Both the query and the notes arrive as unsaved text you review — nothing it sends is written to a file or a database.

Off.

Stored in your system keychain, never in a config file. Regenerating stops every client already configured with the old one.
